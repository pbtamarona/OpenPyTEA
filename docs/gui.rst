Graphical User Interface
========================

.. note::

   The GUI is still in development and may not yet offer all the
   features of the Python package.

OpenPyTEA includes a graphical user interface (GUI) that lets you perform
a complete techno-economic assessment — equipment costing, plant
configuration, results, sensitivity/tornado analysis, Monte Carlo, and
multi-plant comparison — without writing any Python code.

Installing
----------

Installers for **Windows** (``.exe``/``.msi``) and **macOS** (``.dmg``)
are available on the
`Releases page <https://github.com/pbtamarona/OpenPyTEA/releases>`_.
The desktop app is fully self-contained: no Python or Node.js required.

Source and documentation
------------------------

The GUI's source code lives in the repository next to the library
(``frontend/`` and ``backend/``). Run-from-source instructions are in the
`README <https://github.com/pbtamarona/OpenPyTEA#readme>`_, the installer
build process in
`PACKAGING.md <https://github.com/pbtamarona/OpenPyTEA/blob/main/PACKAGING.md>`_,
and the architecture in
`GUI_ARCHITECTURE.md <https://github.com/pbtamarona/OpenPyTEA/blob/main/GUI_ARCHITECTURE.md>`_.
